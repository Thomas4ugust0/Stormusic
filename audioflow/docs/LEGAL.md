# Aviso legal e uso aceitável

A AudioFlow é uma ferramenta técnica. **Você é responsável pelo uso que faz dela.**

- Baixar conteúdo do YouTube pode violar os Termos de Serviço do YouTube e direitos autorais de terceiros.
  Use apenas com conteúdo **seu**, em **domínio público**, sob licença que permita download
  (ex.: Creative Commons) ou com autorização expressa do titular.
- Por isso a API exige `terms_accepted: true` (configurável por `REQUIRE_TERMS_ACCEPTANCE`).
- A API não contorna DRM, paywalls, restrições de idade, conteúdo privado, não listado sem acesso, nem
  transmissões ao vivo: esses casos falham com códigos específicos.
- Não redistribua os arquivos gerados. Os resultados são temporários e removidos automaticamente.
- Operadores devem manter logs mínimos, respeitar pedidos de remoção e cumprir a legislação local
  (ex.: LGPD, Lei 9.610/98 no Brasil).
- SponsorBlock é um serviço comunitário de terceiros; a remoção de patrocínios é de melhor esforço.

Este documento não é aconselhamento jurídico.
